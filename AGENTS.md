## Engineering rules
1. Inspect the existing repository before coding.
2. Never overwrite working code without approval.
3. Explain the design before major implementation.
4. Use modular and maintainable code.
5. Validate all inputs and uploaded files.
6. Write tests for every implemented feature.
7. Run tests and report actual results.
8. Never fabricate AI predictions, confidence,
   citations or accuracy.
9. Never claim a feature works without testing.
10. Never push or merge without Ram's approval.

## Workflow
Understand -> Design -> Implement -> Test ->
Analyse -> Fix -> Approval.
